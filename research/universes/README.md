## 数据口径

`us_liquid_candidates_2026-10-09.csv` 保存核验字段；
`us_liquid_candidates_2026-10-09_sources.json` 保存行情与资格名单的源记录。

市值来自各股票的 Stock Analysis Statistics 页面；盘中页面时间不同，市值为页面报告的近似数。
近 90 日平均成交额来自 IBKR 的 `avg_90d_usd_volume` 行情字段，单位为美元。
最新价与 UTC 行情时间来自 IBKR `last`；本表不是同一时刻的同步报价，也不是当日收盘价。
小数股名单下载地址：https://www.ibkr.com/download/fracshare_stk.csv 。
